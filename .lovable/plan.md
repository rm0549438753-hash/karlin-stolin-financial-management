## מטרה
מערכת בעברית (RTL) לניהול תנועות הכנסה/הוצאה של מוסדות קרלין על פני מספר קופות (חשבונות בנק, מזומן, צ'קים), עם דוחות, סינונים והרשאות.

## תפקידים והרשאות
- **התחברות** באימייל וסיסמה (Lovable Cloud).
- **מנהל (admin):** הכל - כולל ניהול משתמשים, הגדרות (קופות/קטגוריות), מחיקת תנועות, ייצוא.
- **עורך (editor):** הוספה/עריכה של תנועות בלבד, צפייה בדוחות. אין מחיקה ואין הגדרות.
- שני התפקידים רואים את כל הקופות.

## מבנה נתונים (טבלאות)
- `profiles` – פרטי משתמש (שם, אימייל).
- `user_roles` – role enum ('admin','editor') בטבלה נפרדת + פונקציית `has_role` (security definer).
- `kupot` – קופות (שם, סוג: בנק/מזומן/צ'קים, מטבע, פעיל).
- `categories` – קטגוריות (שם, סוג: הכנסה/הוצאה/שניהם).
- `subcategories` – תת-קטגוריות (שם, קטגוריית-אב).
- `expense_types` – "סוג הוצאה" (כוללים, בית אד"ש, משרד, אקספו וכו').
- `transactions` – תנועות:
  - kupa_id, transaction_date, value_date
  - amount (מספרי, חיובי=זכות/הכנסה, שלילי=חובה/הוצאה), balance (אופציונלי)
  - description, reference (אסמכתא), fee (עמלה), channel (ערוץ ביצוע)
  - expense_type_id, category_id, subcategory_id, note
  - created_by, updated_by, timestamps
- RLS: כולם מאומתים רואים ועורכים לפי תפקיד.

ריק = בלי קטגוריה (כפי שביקשת – לא מייבא נתונים מהאקסל; רק רשימות ההגדרות).

## ממשק (RTL, עברית)
מסכים:
1. **לוח בקרה (Dashboard)** – KPI: סה"כ הכנסות החודש, הוצאות החודש, מאזן, יתרה לפי קופה. גרפים: הכנסות מול הוצאות (12 חודשים), פילוח הוצאות לפי קטגוריה (Donut), 5 קטגוריות מובילות, תזרים יומי.
2. **תנועות** – טבלת-על עם:
   - חיפוש חופשי, פילטרים: קופה, סוג, קטגוריה, תת-קטגוריה, טווח תאריכים, סכום מ-עד.
   - מיון לכל עמודה, עימוד, סך נראה למטה.
   - כפתורים: תנועה חדשה, עריכה מהירה inline, ייצוא ל-CSV/Excel.
3. **טופס תנועה** – דיאלוג: קופה, תאריך, סכום (זכות/חובה toggle), תיאור, אסמכתא, עמלה, ערוץ, סוג, קטגוריה, תת-קטגוריה (נטענת לפי קטגוריה), הערה.
4. **דוחות**:
   - סיכום כללי לפי טווח תאריכים.
   - פילוח לפי קטגוריה / תת-קטגוריה (drill-down).
   - השוואת קופות וחודשים (Pivot: שורות=קטגוריה, עמודות=חודש/קופה).
   - חריגות והתראות: תנועות חורגות מ-X ש"ח, תנועות לא מקוטלגות, ימים ללא תנועות בקופה פעילה.
5. **הגדרות (admin בלבד):** ניהול קופות, סוגים, קטגוריות, תת-קטגוריות, משתמשים והרשאות.
6. **התחברות / רישום** – /auth.

## עיצוב
- עברית RTL מלאה. גופן Heebo או Assistant. פאלטה רגועה מקצועית (כחול/אינדיגו עם ירוק להכנסות ואדום-כתום להוצאות). כרטיסים נקיים, צללים עדינים, טבלאות עם zebra stripes.
- shadcn/ui + Tailwind + Recharts לגרפים.

## טכנולוגיה
TanStack Start + React + Tailwind + shadcn. Lovable Cloud עבור DB, Auth, ו-RLS. כל הקריאות לבסיס הנתונים דרך client או server functions.

## תוכנית בנייה (סדר ביצוע)
1. הפעלת Lovable Cloud + auth (אימייל/סיסמה).
2. הגדרות עיצוב (RTL, עברית, פאלטה, גופן).
3. סכמת DB: enums, טבלאות, RLS, has_role, seed של רשימות ההגדרות מהאקסל (קופות, סוגים, קטגוריות, תת-קטגוריות).
4. שכבת auth + ניתוב מוגן + עמוד /auth.
5. Layout כללי עם sidebar RTL ו-header.
6. עמוד תנועות (טבלה + פילטרים + טופס יצירה/עריכה).
7. עמוד דשבורד עם KPI וגרפים.
8. עמוד דוחות (סיכום, פילוח, פיבוט, חריגות) + ייצוא ל-CSV.
9. עמוד הגדרות לאדמין (CRUD לקופות/קטגוריות + ניהול תפקידי משתמשים).
10. ליטוש, בדיקות, ופרסום.

המשתמש הראשון שיירשם יוגדר אוטומטית כאדמין; אחרים יהיו editors כברירת מחדל וניתן לשנות בהגדרות.
