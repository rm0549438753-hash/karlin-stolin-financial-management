# גיבוי יומי אוטומטי ל-Google Drive

## מה ייבנה

מערכת שכל יום ב-02:00 (שעון ישראל) יוצרת קובץ Excel עם כל הנתונים ומעלה אותו לתיקייה ייעודית בגוגל דרייב, עם שמירה של 30 יום אחרונים.

## שלבים

### 1. חיבור Google Drive
- קישור מחבר `google_drive` לפרויקט (OAuth) — נשמור את הקבצים בחשבון הדרייב שיחובר.
- ביצירה הראשונה של הגיבוי, נוצרת אוטומטית תיקייה בשם **"גיבויים - מרכז קארלין סטולין"** בשורש הדרייב, ה-ID שלה נשמר בהגדרות.

### 2. תוכן קובץ ה-Excel
קובץ יחיד עם לשוניות נפרדות:
- תנועות (כל 9,000+ השורות)
- חשבונות
- קופות
- סוגים (expense_types)
- קטגוריות
- תת-קטגוריות
- היסטוריית פעילות (action_history — כולל הכל, לא רק 50 אחרונות)
- sync_ignores
- פרופילים והרשאות (user_roles + profiles)

שם קובץ: `backup-YYYY-MM-DD.xlsx`

### 3. Server route
`src/routes/api/public/hooks/daily-backup.ts` — POST endpoint שמאומת ע"י `apikey` header:
- שולף את כל הטבלאות (עם pagination של 1000, כמו בלוח הבקרה).
- בונה workbook עם `xlsx` (Worker-compatible).
- מעלה ל-Drive דרך `connector-gateway.lovable.dev/google_drive/upload/drive/v3/files?uploadType=multipart`.
- מוחק קבצים ישנים מ-30 יום באותה תיקייה.
- מחזיר JSON עם סטטוס, שם קובץ, וגודל.

### 4. תזמון (pg_cron)
משימה יומית ב-**23:00 UTC** (= 02:00 שעון ישראל בקיץ / 01:00 בחורף — אשאל אותך אם עדיף להתאים לפי שעון חורף):
```sql
select cron.schedule(
  'daily-backup-to-drive',
  '0 23 * * *',
  $$ select net.http_post(url:='.../api/public/hooks/daily-backup', ...) $$
);
```

### 5. פאנל ניהול בהגדרות
בלשונית "הגדרות" מנהל, סקציה חדשה **"גיבוי יומי"**:
- מציגה מתי הגיבוי האחרון רץ, שם הקובץ, וסטטוס (הצלחה/כשל).
- כפתור **"הפעל גיבוי עכשיו"** להרצה ידנית.
- כפתור **"פתח תיקיית גיבויים בדרייב"**.
- טבלה קטנה של 30 הריצות האחרונות.

טבלה חדשה `backup_runs` (id, started_at, finished_at, status, file_name, file_id, size_bytes, error_message, row_counts jsonb).

## הערות טכניות
- לשונית "היסטוריית פעילות" בקובץ תכלול את כל הרשומות מ-`action_history` (גם אחרי שמחקנו את מגבלת ה-50 בתצוגה).
- 30 יום אחורה: הניקוי מתבסס על שם הקובץ (תאריך) ולא על מטה-דאטה של Drive — אמין יותר.
- אבטחה: ה-endpoint תחת `/api/public/*` (עוקף auth), אבל דורש `apikey` header עם ה-anon key של הפרויקט.

## שאלה פתוחה
שעון קיץ/חורף בישראל משנה ±שעה. אני מציע לנעול ל-**23:00 UTC** (02:00 בקיץ, 01:00 בחורף) — זה פשוט ואמין. אם חשוב שיהיה בדיוק 02:00 כל השנה, נצטרך פתרון מורכב יותר. אישור?
