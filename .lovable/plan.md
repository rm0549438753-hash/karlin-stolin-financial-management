## מטרה
להוסיף ניהול מלא לריצות אחרונות (גיבוי יומי + מייל צ'קים) ולאפשר עריכת הגדרות המייל היומי (נמענים, נושא, גוף).

## 1. ריצות אחרונות — ניהול מלא (שני הפאנלים)

בכל שורת ריצה ב-`BackupPanel` וב-`UpcomingChecksEmailPanel`:
- **חץ הרחבה** לפתיחת פאנל פרטים בתוך השורה (accordion), עם:
  - זמן התחלה/סיום, משך, מי הפעיל (cron/ידני), סטטוס
  - שגיאה מלאה (אם יש) בקופסה ניתנת להעתקה
  - גיבוי: רשימת טבלאות + מספר שורות שגובו + קישור לתיקייה
  - מייל צ'קים: נמענים, נושא, מספר צ'קים, סה"כ סכום, קישור לצ'קים במערכת
- **כפתור מחיקה** (סמל פח) — עם דיאלוג אישור, מוחק את שורת ההיסטוריה בלבד (`backup_runs` / `check_email_runs`). לא נוגע בקבצי הדרייב או במיילים שכבר נשלחו.
- **כפתור הרצה מחדש** (סמל refresh):
  - גיבוי: מפעיל `runBackupNow` חדש (לא ממשיך את הישן)
  - מייל צ'קים: מפעיל שליחה מחדש עבור **אותו value_date** של הריצה המקורית (לא בהכרח מחר). הוספת פרמטר `targetDate` ל-server function.
- הרשאות: מחיקה/הרצה מחדש → רק admin. viewer/editor רואים בלבד.

## 2. עריכת הגדרות מייל צ'קים

הוספת טאב/כרטיס חדש "הגדרות המייל" בתוך `UpcomingChecksEmailPanel`, מעל היסטוריית הריצות.

### 2א. טבלה חדשה `check_email_settings`
שורה יחידה (singleton) עם:
- `recipients` (text[]) — רשימת נמענים
- `subject_template` (text) — נושא עם משתנים
- `body_intro` (text) — פסקת פתיחה מעל הטבלה
- `body_outro` (text) — פסקת סיום מתחת לטבלה
- `include_association` / `include_note` (bool) — עמודות אופציונליות בטבלה
- `send_when_empty` (bool) — האם לשלוח מייל גם אם אין צ'קים למחר
- `updated_at`, `updated_by`

RLS: קריאה — כל משתמש מאומת. עדכון — admin בלבד. + GRANTs.

### 2ב. משתנים דינמיים (placeholders)
בנושא ובגוף אפשר להשתמש ב:
- `{{date}}` — תאריך מחר (עברית: "13 ביולי 2026")
- `{{day_name}}` — שם היום ("יום ראשון")
- `{{count}}` — מספר צ'קים
- `{{total}}` — סה"כ סכום מעוצב
- `{{org_name}}` — "מרכז קארלין סטולין"

ברירות מחדל:
- נושא: `צ'קים לפירעון {{day_name}} {{date}} — {{count}} צ'קים, סה"כ {{total}}`
- פתיחה: `שלום,\nלהלן פירוט הצ'קים הצפויים להיפרע {{day_name}} {{date}}:`
- סיום: `בברכה,\n{{org_name}}`

### 2ג. עיצוב הפאנל
```text
┌─ הגדרות המייל היומי ──────────────────┐
│ נמענים (chips ניתנים להסרה + הוספה)   │
│ ┌────────────────────────────────┐    │
│ │ RM0549438753@gmail.com  ✕      │    │
│ │ 5326725@gmail.com       ✕      │    │
│ │ [+ הוסף נמען]                  │    │
│ └────────────────────────────────┘    │
│                                        │
│ נושא המייל: [_____________________]   │
│                                        │
│ פסקת פתיחה:  [textarea]                │
│ פסקת סיום:   [textarea]                │
│                                        │
│ ☑ הצג עמודת עמותה                     │
│ ☑ הצג עמודת הערה                      │
│ ☐ שלח גם אם אין צ'קים                 │
│                                        │
│ משתנים זמינים: {{date}} {{day_name}}...│
│                                        │
│ [תצוגה מקדימה]  [שמור שינויים]        │
└────────────────────────────────────────┘
```
- כפתור **תצוגה מקדימה** פותח דיאלוג עם רינדור אמיתי של המייל (RTL) לפי הצ'קים של מחר.
- כפתור **שלח עכשיו לבדיקה** הקיים ישתמש בהגדרות שנשמרו.

## 3. שינויים בקוד — סיכום טכני

- **DB migration**: יצירת `check_email_settings` + GRANT + RLS + שורה ראשונית עם ברירות המחדל.
- **`src/lib/checks-email.server.ts`**: קריאת הגדרות מהטבלה, החלפת placeholders, בניית טבלת HTML לפי דגלי include, תמיכה ב-`targetDate` מפורש.
- **`src/lib/backup.functions.ts`** + **`src/lib/checks-email.functions.ts`**: server functions חדשים — `deleteBackupRun`, `deleteCheckEmailRun`, `rerunCheckEmail(runId)`, `getCheckEmailSettings`, `updateCheckEmailSettings`, `previewCheckEmail`.
- **`BackupPanel.tsx`** + **`UpcomingChecksEmailPanel.tsx`**: הרחבת השורות (Collapsible של shadcn), כפתורי מחיקה/הרצה, פאנל הגדרות חדש, דיאלוג תצוגה מקדימה.
